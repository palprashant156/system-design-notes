# Caching

Let's understand caching with the help of an example. Let's say we are using anything frequently, like fetching the OTP, balance, or user profile. It is very fast to fetch because, when we do not use caching, it goes to the origin database and retrieves it from there, so it is a very costly and time-consuming process to do.

## Uses
* Mostly used in read-intensive tasks
* Static content
