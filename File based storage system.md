# File-Based Storage System

A file-based system is a database management system where data is stored in the form of files.

### Challenges of File-Based Storage System:
1. **Data Redundancy and Inconsistency:**
   * *Example:* Let's say two persons, Ram and Shyam, both have the same file named `file1.txt`. So if data is updated by a colleague, then the data is not consistent.
2. **Poor Security:** The same data is present in the system, which causes a possibility of data breaches by unauthorised users.
3. **Slow:** The data retrieval is very slow.
